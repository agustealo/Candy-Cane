# Candy Cane screenshot assets

This directory contains the canonical public documentation screenshots for Candy Cane.

The images are **not hand-authored mockups**. They are generated from a clean WordPress runtime by `tests/docs-showcase.sh` and captured with the pinned Playwright pipeline in `tests/browser/docs-showcase.mjs`. Editorial post dates and the showcase comment timestamp are fixed fixture data so the captures remain reproducible instead of drifting with CI wall-clock time.

## Canonical documentation files

- `desktop-home.png` — primary repository/README hero
- `desktop-single.png` — editorial single-post presentation
- `desktop-page.png` — standard page plus right sidebar/widgets
- `tablet-home.png` — tablet home-grid behavior
- `mobile-home.png` — compact home experience
- `mobile-single.png` — compact editorial experience
- `desktop-keyboard-overlay.png` — keyboard-visible post-card overlay
- `showcase-manifest.json` — generated route and viewport metadata

The root `screenshot.png` is the separate WordPress theme-selection preview. It is also generated by this same showcase pipeline at 1200×900 from the real Candy Cane runtime, so the package preview and documentation visuals share one deterministic source of truth.

Do not edit the PNGs by hand. The `Docs Showcase` workflow regenerates them on same-repository pull requests and verifies the committed `master` copies against the deterministic runtime.

Regression screenshots under `tests/browser-artifacts/` serve a different purpose and must not be substituted for these product-facing images.

The entire `docs/` tree is excluded from the customer-installable theme ZIP. The root `screenshot.png` intentionally remains in the ZIP as part of the WordPress theme package.
